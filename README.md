# AI Excited — "Ink Leap"

A colossal koi fish leaps out of a giant overturned inkwell, ink exploding
upward into a starry night sky. Bold vermilion, teal and gold on deep
indigo — one diagonal burst of motion, one clear focal point: the fish
mid-leap, water droplets frozen in the air.

Why this image: the twist is scale and material — an inkwell the size of a
lake, ink that becomes stars. It reads instantly at small size, feels like
a single frozen moment about to burst, and has no text to garble.

## Entry

- `main.ts` — Node 22 program (stdlib only, no network). It copies the
  repository-held `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png`
  (default `/output`), creating the directory if needed.
- `entry.png` — the 1024×1024 artwork, generated for this entry.
- Deterministic: running twice produces byte-identical output.
